# Kalender Dinamis

## Deskripsi
Kalender Dinamis adalah website yang digunakan untuk menampilkan kalender secara interaktif. Pengguna dapat melihat tanggal berdasarkan bulan dan tahun, berpindah ke bulan sebelumnya atau berikutnya, serta memilih tanggal tertentu untuk menambahkan catatan atau agenda.
Website ini dibuat menggunakan HTML, CSS, JavaScript

## Tujuan
Project ini dibuat untuk menerapkan penggunaan HTML, CSS, dan JavaScript, selain itu juga dapat membuat kalender yang dapat menampilkan tanggal secara dinamis, memudahkan pengguna berpindah bulan, menambahkan catatan atau kegiatan pada tanggal tertentu, membuat kalender yang dapat digunakan pada berbagai ukuran layar.

## Fitur
- Menampilkan kalender berdasarkan bulan dan tahun.
- "<" Berpindah ke bulan sebelumnya.
- ">" Berpindah ke bulan berikutnya.
- Tombol "Today" untuk kembali ke tanggal sekarang.
- Input MM/YYYY untuk menuju bulan tertentu.
- "+" Menambahkan event atau catatan.
- Menambahkan waktu pada event.
- "_" Memberikan tanda pada tanggal yang memiliki event.
- Menyimpan event menggunakan Local Storage.
- Tampilan responsive untuk berbagai ukuran layar.

## Teknologi
- HTML → membuat struktur kalender.
- CSS → mengatur tampilan dan responsive.
- JavaScript → mengatur fungsi dan interaksi kalender.
- Local Storage → menyimpan data event.
